# 01. 서비스 흐름 및 화면 명세

## 목적
냉털셰프의 화면과 사용자 흐름을 구현 전에 고정한다. 첨부 UI 참고 이미지가 제공되지 않았으므로 아래 명세를 기본 디자인 기준으로 사용한다.

## 화면 흐름
`재료 입력 → 조건 선택 → AI 추천 요청 → 레시피 확인 → 피드백 작성 → 최신 피드백 확인`

## 화면 영역
### A. 헤더
- 로고 텍스트: 냉털셰프
- 보조 문구: 냉장고 속 재료로 오늘의 메뉴를 찾아보세요.
- 별도 로그인 메뉴는 만들지 않는다.

### B. 식재료 입력
- 텍스트 입력창과 `재료 추가` 버튼
- Enter 키로도 추가 가능
- 입력한 재료는 칩 형태로 표시하고 칩마다 삭제 버튼 제공
- 빈 목록에는 예시 재료 추가 버튼 표시

### C. 요리 조건
- 인원수 선택(1~8명)
- 조리 시간 선택(15분, 30분, 45분, 제한 없음)
- 제외/주의 재료 입력
- 선호 조건 입력

### D. 추천 실행
- `요리 추천받기` 버튼
- 요청 중에는 스피너 또는 진행 문구 표시
- 요청 중 재클릭 방지

### E. 결과
- 최대 3개의 레시피 카드
- 카드 내부: 요리명, 소개, 시간, 난이도, 보유 재료 사용량, 추가 재료, 단계별 조리법, 주의사항
- 카드별 `레시피 복사` 버튼
- 결과가 없을 때는 재료나 조건을 바꾸어 다시 요청하도록 안내

### F. 피드백
- 피드백 유형 선택
- 별점 선택(선택 사항)
- 내용 입력
- 공개 목록에 표시된다는 개인정보 안내
- 전송 버튼과 성공/실패 상태

### G. 피드백 목록
- 화면 하단에 배치
- 최신순
- 유형, 별점, 내용, 작성 시각 표시
- 최근 50개까지만 표시

## UI 방향
- 따뜻하고 신선한 주방 분위기
- 아이보리/크림 배경, 짙은 녹색 포인트, 오렌지 보조 포인트
- 둥근 카드와 충분한 여백
- 식재료 칩은 한눈에 구분되게 구성
- 과도한 애니메이션이나 장식은 사용하지 않는다.
- 모바일에서는 한 열, 넓은 화면에서는 입력/조건을 적절히 나누되 결과 카드는 읽기 쉽게 배치한다.

## 반응형 기준
- 360~767px: 한 열, 버튼은 충분한 터치 영역 확보
- 768~1023px: 입력 영역 2열 가능
- 1024px 이상: 콘텐츠 최대 너비 1120px, 가운데 정렬

## 접근성
- 모든 입력 요소에 label 연결
- 버튼은 명확한 텍스트 제공
- 상태 메시지는 `aria-live` 영역에 표시
- 색상 외에 텍스트/아이콘으로 상태 표현
- 포커스 표시를 제거하지 않는다.
